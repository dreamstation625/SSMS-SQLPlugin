## 4. ⚠️ 重大发现：22.11 重构了编辑器契约

**`SqlScriptEditorControl` 这个类型在 22.11 里彻底消失了。**

- 全盘搜索 `...\IDE\**\*.dll`，零命中
- 取而代之的是 `Microsoft.SqlServer.Management.UI.VSIntegration.SqlEditor.BrokeredContracts.dll`

**影响**：

1. 网上大量 SSMS 扩展教程（含 2025 年的项目）用的都是
   `反射 → SqlScriptEditorControl → ScriptFactory → CurrentConnection` 这条老路。
   **这些代码在 22.11 上编译不过，也反射不到。**
2. 我们方案里「拿连接」的实现必须走 **`ISqlEditorService` 契约**，不能照抄社区代码。
3. 反过来说这是好事：走契约比反射稳，说明微软把它当成扩展点了。

**这件事本身就证明了方案 §12 第一条风险是真实的**：SSMS 的 service release 会动内部结构。适配层 + 运行时探测的设计不是过度设计。
