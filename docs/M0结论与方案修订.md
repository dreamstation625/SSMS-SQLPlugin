## 3. 被实测推翻或修正的原始设计

这一节最重要：**照原方案写代码会踩空的地方，全在这里。**

| # | 原方案 | 实测结论 | 影响 |
|---|---|---|---|
| 1 | 菜单用 VSCT / CTC / `.ctmenu` | **完全弃用**。CTC 在 SSMS 22.11 上不生效（试了 7 种配置） | 删掉 VSCT 相关全部工作量，改运行时注入 |
| 2 | — | **`ISqlEditorService` 必须用 `SSqlEditorService`（服务 ID 类）获取**，传接口类型是 null | 适配层必须反射，不能强类型引用 |
| 3 | SQLite 要独立 AppDomain 隔离 | **不需要**。复用宿主 `PublicAssemblies\SQLite` 即可，不打包 native | 删掉 `Storage.Isolation` 工程、跨域 DTO |
| 4 | — | **`ITextView` 不能出现在包类型的方法签名/字段里**，否则包静默不加载 | 包层只能用 `Shell.*` / `TextManager.Interop` / `OLE.Interop` |
| 5 | pkgdef 未规定编码 | 必须是 **UTF-16 LE + BOM**（与微软自带一致） | 打包脚本要转码 |
| 6 | `InprocServer32` 指向托管 DLL | 必须指向 **`$WinDir$\SYSTEM32\MSCOREE.DLL`**，否则 COM 激活静默失败 | pkgdef 模板固定 |
| 7 | 命令表资源 `Menus` 段 | `AutoLoadPackages` 的键是 UICONTEXT、值是包 GUID（原方案写反过） | 已修正，见踩坑文档 §3.2 |

## 4. 开发基线（照这个写）

### 4.1 包的最小骨架

```
SsmsSqlPlugin.Host.V22/
├── XxxPackage.cs              继承 AsyncPackage，只做服务注册和装配
├── SSMS-SQLPlugin.pkgdef      UTF-16 LE + BOM，三段：Packages / AutoLoadPackages / (可选)ToolWindows
├── extension.vsixmanifest     VsPackage + MefComponent 两个 Asset 都要声明
└── 其他逻辑一律放独立类库
```

pkgdef 模板（**照抄，别改结构**）：

```
[$RootKey$\Packages\{包GUID}]
@="显示名"
"Class"="命名空间.包类"
"Assembly"="程序集名, Version=x.y.z.0, Culture=neutral, PublicKeyToken=null"
"InprocServer32"="$WinDir$\SYSTEM32\MSCOREE.DLL"
"CodeBase"="$PackageFolder$\程序集名.dll"
"AllowsBackgroundLoad"=dword:00000001

[$RootKey$\AutoLoadPackages\{UICONTEXT GUID}]
"{包GUID}"=dword:00000002
```

### 4.2 四条关键 API 的获取方式

**菜单 / 命令（运行时注入）**

```csharp
// 1) 注册命令（IVsProfferCommands3！不是 1 或 2，那两个在 SDK 里不可见）
var proffer = GetService(typeof(SVsProfferCommands)) as IVsProfferCommands3;
int hr = proffer.AddNamedCommand(ref pkgGuid, ref cmdSet, "Canonical.Name", out cmdId,
    "本地化名", "按钮文字", "提示", null, 0, 0, 1, 0, new Guid[0]);
// hr==0 新注册；hr==1(S_FALSE) 已存在；两者都算成功，只有 hr<0 才失败

// 2) 挂按钮（必须强类型，dynamic 会 RuntimeBinderException）
var cmdBars = dte.CommandBars as Microsoft.VisualStudio.CommandBars.CommandBars;
var tools = (CommandBarPopup)cmdBars["MenuBar"].Controls[i];  // 按 Caption 匹配"工具(&T)"
var btn = (CommandBarButton)tools.Controls.Add(MsoControlType.msoControlButton,
    Type.Missing, Type.Missing, 1, true);
btn.Caption = "...";
btn.Click += OnClick;
```
**不要用** `AddCommandBarControl`（返回 `E_NOINTERFACE`）。

**补全**

```csharp
[Export(typeof(IAsyncCompletionSourceProvider))]
[ContentType("SQL")]                       // 实测内容类型名就叫 "SQL"
[Name("SsmsSqlPlugin.Completion")]
internal sealed class MyProvider : IAsyncCompletionSourceProvider { ... }
```
命名空间 `Microsoft.VisualStudio.Language.Intellisense.AsyncCompletion`（接口）和 `.Data`（数据类）。
**清单必须声明** `<Asset Type="Microsoft.VisualStudio.MefComponent" Path="xxx.dll" />`，否则 Shell 不扫这个 DLL。

**连接**

```csharp
// 必须用 S 类当服务键；接口是 SSMS 内部类型，只用反射，不编译期引用
Type svcType   = /* 遍历已加载程序集找 Name=="ISqlEditorService" */;
Type svcIdType = /* 同程序集里 Name=="SSqlEditorService"（GUID 72BB0B14-2D2B-454A-B0AC-1890C2994A22） */;
object svc = GetService(svcIdType);         // 得到 SqlEditorService 实例

// 拿到的是「连接描述」，不是活连接！

string server  = conn.DataSource;    // "localhost,11433"
string database= conn.Database;      // "master"
string cs      = conn.ConnectionString;   // 含明文密码，日志必须脱敏

// ⚠️ conn.State == Closed，不能直接 Execute。查元数据要自己另开：
using (var mine = new SqlConnection(cs)) { mine.Open(); /* ... */ }

// 其他方法：GetActiveEditorMoniker()->string（编辑器标识）
// 事件：ConnectionChanged / ConnectionDisconnected / CaptionChanged（缓存失效钩子）
```

**执行捕获**

```csharp
// IOleCommandTarget 挂到 IVsTextView 命令链
var filter = new CommandFilter(vsView);
vsView.AddCommandFilter(filter, out var next);
filter.Next = next;

// Exec 里判断：pguidCmdGroup == {1496a755-94de-11d0-8c3f-00c04fc2aae2} && nCmdID == 0x0067
```

**存储**

```csharp
// 从宿主目录加载，顺序不能变
var dir = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "PublicAssemblies", "SQLite");
Assembly.LoadFrom(Path.Combine(dir, "SQLitePCLRaw.core.dll"));
Assembly.LoadFrom(Path.Combine(dir, "SQLitePCLRaw.provider.e_sqlite3.dll"));
var bat = Assembly.LoadFrom(Path.Combine(dir, "SQLitePCLRaw.batteries_v2.dll"));
bat.GetType("SQLitePCL.Batteries_V2").GetMethod("Init", Type.EmptyTypes).Invoke(null, null);
// 再 LoadFrom("SQLite-net.dll")，反射构造 SQLiteConnection(databasePath, true)
```
**不要打包** SQLite / SQLitePCLRaw / native 到 VSIX。

### 4.3 部署铁律

```bash
# 1. 杀干净（一次常杀不掉）
for i in 1 2 3; do taskkill //F //IM SSMS.exe; sleep 2; done
# 2. 确认进程数为 0，否则日志会被多个实例抢占，造成"包没加载"的假象
# 3. 覆盖文件到用户级扩展目录
# 4. 必须刷新配置标记，否则 Shell 用旧缓存
touch "%LOCALAPPDATA%\Microsoft\SSMS\22.0_<instance>\Extensions\extensions.configurationchanged"
# 5. 换版本时三处版本号要一起改：csproj / extension.vsixmanifest / pkgdef 的 Assembly=
```

### 4.4 架构约束（硬规则）

1. **包类型（`AsyncPackage` 子类）及它直接引用的类型**，方法签名 / 字段 / 属性里只能出现宿主必然会加载的程序集：`Microsoft.VisualStudio.Shell.*`、`TextManager.Interop`、`OLE.Interop`、`mscorlib`。
   `ITextView` / `ITextBuffer` 这类放到内部私有类里用。
2. **宿主内部接口一律反射**，不强类型引用，全部包 try/catch 并可降级。
3. **纯逻辑（排版、存储、元数据）放独立类库**，不引用任何宿主程序集，可单元测试。
4. **不要在按键路径上调宿主服务**（连接查询忙时实测 1908ms）。
